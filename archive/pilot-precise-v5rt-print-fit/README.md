# Pilot Precise V5RT print-fit trials

These eight configurations differ only in nose insertion diameter (7.57–7.78 mm). They were test prints, not separate pen designs. Mach 3 now has a single 7.40–7.45 mm fit sweep for the measured 8 mm brass tube.

The trial files are kept here for reference and are excluded from both galleries and the designer's Starting design list.
