# Pilot Precise V5RT print-fit trials

These seven archived configurations differ from the active Pilot Precise V5RT design only in nose insertion diameter (7.60–7.78 mm). They were test prints, not separate pen designs. The original 7.57 mm design remains in the gallery with a 7.40–7.50 mm fit sweep for the measured 8 mm brass tube. Mach 3 has the same sweep.

The trial files are kept here for reference and are excluded from both galleries and the designer's Starting design list.
